Elementos de un formulario web

HTML ofrece diferentes controles

Campo de texto

Permite escribir una línea de texto <input type="text">

Contraseña

Texto oculto por seguridad <input type="password">

Correo Electrónico

Para direcciones email <input type="email">

Número

Permite introducir números <input type="number">

Teléfono

Para números de teléfono <input type="tel">

URL

Para direcciones web <input type="url">

Búsqueda

Campo de búsqueda <input type="search">

Fecha

Fecha <input type="date">

Color

Elige un color <input type="date">

Rango

Permite introducir un valor dentro de un rango <input type="date">

Radio

Permite introducir un valor dentro de un rango <input type="radio">

Lista despegable

Permite seleccionar una opción en una lista <select>

Área de texto

Permite incluir texto en varias líneas <textarea>

Lista de datos

Permite sugerencias <input list="">

Subida de archivos

Seleccionar <input type="file">
